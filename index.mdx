This site documents the internals of NestJS as they exist in the repository at commit `a3a31b9`. Every page cites the concrete files, classes, and symbols that implement the behavior it describes so you can jump from the docs to the source and audit any claim.

The scope is what the code actually supports today: application bootstrap and lifecycle, the module graph and dependency-injection container, the HTTP request pipeline, the Express and Fastify platform adapters, the WebSocket gateway system, the microservices transport layer, the testing harness, and the extension points those layers expose (discovery, graph inspection, REPL).

## Reading these docs

Every section links to real files under `packages/` in the source tree. When a page says "see `packages/core/nest-factory.ts`", that file exists at that path in the pinned commit. Classes, methods, decorators, and constants are named as they appear in source so you can grep for them directly.

If a behavior is not documented here, it is because the code at this commit does not support it or because it belongs to a package outside the scope of this reference (for example `@nestjs/graphql` or `@nestjs/typeorm`, which live outside this repository).
